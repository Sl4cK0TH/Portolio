# Zor0ark - Cybersecurity Portfolio

A dark-themed, hacker-inspired portfolio website showcasing my work as a Cybersecurity Researcher and Ethical Hacker.

## 🚀 Features

- **Dark Hacker Theme** - Matrix-style green and cyan color scheme with terminal aesthetics
- **Glitch Effects** - Dynamic binary text glitching and Daft Punk-inspired image strip displacement effects
- **Responsive Design** - Mobile-friendly with hamburger menu navigation
- **Quote Carousel** - Rotating inspirational quotes with smooth transitions
- **Social Media Integration** - Quick links to Facebook, Instagram, LinkedIn, and Email
- **Placeholder Pages** - Coming soon pages for About, Portfolio, Blog, Achievements, and CTF Writeups

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Custom properties, animations, flexbox layouts
- **Vanilla JavaScript** - Dynamic effects and interactivity
- **Font Awesome 6.5.1** - Icon library for social media buttons

## 🚦 Getting Started

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/yourusername/Portolio.git
cd Portolio
```

2. Start a local server:
```bash
python3 -m http.server 8000
```

3. Open your browser and navigate to:
```
http://localhost:8000
```

## ✨ Key Features

### Glitch Effects
- **Text Glitch**: Title text randomly converts letters to binary (0s and 1s)
- **Image Glitch**: Profile image splits into 100 horizontal strips with random displacement animation

### Responsive Navigation
- Desktop: Full horizontal navigation bar
- Mobile: Hamburger menu with slide-down navigation

### Quote Carousel
- 5 rotating inspirational quotes
- Auto-rotation every 6 seconds
- Manual navigation with clickable dots
